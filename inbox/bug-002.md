# Support ticket — Briarwood Retail Group

**From:** Marcus Oyelaran (Integrations Engineer, Briarwood Retail Group)
**Date:** 2026-09-13
**Product area:** API authentication
**Platform version:** 2.5
**Client-reported severity:** High

## Description

Our sync worker's API calls start failing with 401 Unauthorized after it's
been running for a while — roughly an hour, as far as we can tell.
Restarting the worker fixes it immediately, which is why we think this is on
your end: nothing about our credentials or account changed.

## Steps to reproduce

1. Start our sync worker fresh (it authenticates and gets a token)
2. Let it run continuously making API calls
3. After roughly 60 minutes, calls start returning 401
4. Restart the worker — works again immediately

## Business impact

We've had to add an hourly cron restart on the worker as a workaround, which
feels wrong and occasionally causes us to drop a sync cycle if the restart
overlaps with a scheduled job.
